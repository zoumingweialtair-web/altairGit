# Little Elsewhere · 窗外小世界

一个以观鸟、小动物与虫类来访、收集风景、幻想奇遇和 lofi 陪伴为核心的 Godot 2D 原型。打开一扇窗，看窗台、花盆、食盘、树、邻楼、宽阔水面、弯曲远岸、山坡上的塔、雪山和天空，慢慢填满自己的观察图鉴。

## 启动与打开工程

双击本目录的 **Play.cmd** 即可游玩，使用本机已经安装的 Godot。修改工程时，双击 **OpenGodot.cmd**；也可以在 Godot 项目管理器点击「导入」，选择本目录的 `project.godot`，打开后按 **F5** 运行。

项目使用 **Godot 4.7.2 标准版 / Compatibility 渲染器**，不需要 .NET。中文使用 Windows 的 Microsoft YaHei 系统字体。启动脚本指向当前电脑的 Godot 安装位置；移动到其他电脑时，请用 Godot 4 导入工程，或修改脚本中的引擎路径。

## 先体验这几个地方

1. 在右上角切换「晴日 / 听雨 / 月夜 / 夕照 / 落雪 / 晨雾 / 风雨 / 晨曦」。天空、云、远山、水面、岸边建筑、树和前景分别组成独立图层；天气会改变整体光色、粒子、来客行为与声音。
2. 在一种天气下观察约 **8 秒**，对应的风景会自动收录，每种风景每天记录一次。原有五种风景之外，新增晨雾、风雨与晨曦。切换天气后重新开始这一段观察。
3. 留意树上的访客，点击来客打开观察卡。晴日的鸟会从枝头飞向食盘；雨雪中更常停在遮蔽处，月夜则安静休息。松鼠、啄木鸟、林鸮和小虫也会带来各自的动作与趣味。
4. 打开图鉴，按「全部 / 鸟类 / 动物 / 昆虫 / 风景 / 奇遇 / 珍藏」筛选。未发现条目显示剪影和线索；发现后可查看插图、观察位置、相遇条件、行为描述、次数、首次与最近观察时间，以及已记录的天气。
5. 把喜欢的条目设为「珍藏」，或回到窗边回放访客与奇遇、重访风景。回放不重复增加观察次数。访客与奇遇回放结束后恢复日常观察；重访风景时，点击天气按钮或开始陪伴可继续观察收录。
6. 点「演示」，默认打开「窗外奇遇 · 10」，可直接观看十个新奇遇；另有「全部奇遇 · 21」与「来客 · 21」两个分页。点击条目会切换到适合观看的天气并播放动画。「模拟离开 24 小时」会生成演示用的离线记录，不修改电脑时间。
7. 打开「窗边布置」，选择谷物食盘、果实小篮、花草角或暖光小灯，试着多认识几位有不同偏好的邻居。访客累计来过五次后，会在档案里留下一份纪念物。
8. 「窗边布置 → 调整陪伴声音」可调整原创合成轻音乐、雨声、风叶与河水。「开始陪伴」会隐藏大部分界面并记录时长，新发现静默保留；结束后再查看本次摘要。

## 已实现的氛围与图鉴

八种天气分别表现晴光与水面亮点、雨幕与河面涟漪、月色与星点、夕照与暖色倒影、落雪与安静树影，以及晨雾、斜雨和初升的晨光。天气切换有渐变过渡，来客和小船也会与环境保持相应的亮度和节奏。宽阔水面由自然弯曲的远岸围合，岸边的凹凸与山脚相接；两座塔分别落在前后不同的山坡，近塔稍清晰，远塔更淡，灯光缓慢闪烁。城镇窗灯与水中倒影也有细微变化。陪伴时动态细节会更轻缓。

图鉴共有 **50 项**：鸟类 10 项、动物 4 项、昆虫 7 项、风景 8 项、奇遇 21 项。收藏、珍藏、带日期的观察记录都保存在本地；旧版七项、十二项、二十二项、四十项图鉴存档都可以继续使用。观察记录保留最近 120 条，已收录的条目与累计次数独立保存。

## 分层场景、奇遇动画与收藏插画

窗外由天空、星点、远云、天空奇遇、远山、远雾、水面、水上奇遇、岸边城镇、树、近处雨雪与窗边前景分层组成。山、岸、树和前景使用独立透明素材，云雾会移动，雨雪粒子持续下落，水面有自己的波纹与光色变化。自然弯曲的远岸和两座有远近差异的山坡塔继续保留；窗框与窗台的位置固定，光线可以随环境改变。

奇遇主体分别挂在天空或水面层：旧神与沉城缓缓升沉，水母与浮岛独立漂移，月亮与星鹿有自己的运动和光效；极光、流星、霞云与蓝潮由独立动态效果表现。每次展示约 **60 秒**，包含进入、停留与退场。连续选择会过渡到最新奇遇；手动切换天气会结束当前奇遇。陪伴时温和的奇遇继续出现，潮下旧神只静默收录，结束陪伴后可以从图鉴回放。

图鉴插画负责辨认与收藏，窗外使用独立主体和图层动画。旧版整张天气背景和十幅整景奇遇图保留为美术参考，已经退出运行时显示。收藏仍为 **50 项**，生物熟悉度、纪念物与事件概率沿用原有规则。

## 布置、熟客与纪念物

四种布置可以随时切换，当前选择会自动保存。每位生物访客都有自己的个性、偏好与小纪念物，图鉴详情会显示它们：

| 布置 | 偏好示例 |
| --- | --- |
| 谷物食盘 | 麻雀、山雀、啄木鸟、燕子 |
| 果实小篮 | 松鼠、绣眼鸟、刺猬、锹甲 |
| 花草角 | 白蝶、蜻蜓、瓢虫、翠鸟 |
| 暖光小灯 | 林鸮、月蛾、窗边猫、蝙蝠 |

布置在兼容天气的候选池中提高偏好访客的权重，其他候选访客依然会自然到来。它不强制召唤、不消耗库存，也不是逐件自由装修。

**21 位生物访客**会从「初次相遇」逐渐变成「熟悉的邻居」，十次后成为「窗边老友」。累计 **5 次**观察即可解锁一份纪念物，例如小羽毛、卷卷落叶或柔软线团。旧存档的次数直接继承，不必重新培养；回放、阅读档案、珍藏和切换布置都不增加来访次数。风景和幻想奇遇仍作为收藏条目，不计算熟悉度或访客纪念物。

## 自动保存与离线记录

新发现、珍藏、布置和声音开关会自动保存，正常关闭窗口也会保存。再次打开时，会按上次保存的时间补算离线期间的来客与稀有相遇，并显示结算结果；风景需要在线驻足观察，不会离线自动解锁。离线事件池包含全部生物访客和奇遇，也会考虑布置偏好。离线来访会计入熟悉度与纪念物条件。

离线补算最多覆盖最近 **30 天**，超出部分会在界面说明，已有收藏不受影响。「模拟离开 24 小时」只用于体验记录流程，多次使用会轮换展示不同稀有条目，不推进真实离线结算时间或保底进度。在线自动事件和手动演示都会写入这份演示进度；回放不增加次数，陪伴模式也不会增加稀有事件的抽取机会。

英文工程目录为 `LittleElsewhere/game`，设计文档位于同级 `docs` 目录。改名后继续使用原有存档位置，已有收藏与观察记录会保留。

Godot 的本地用户目录 `user://` 对应本机的 `%APPDATA%\WindowDiaryDemo`。主存档为 `window_diary_demo_save.json`，状态模块保留备份并支持损坏恢复。自动测试使用独立存档，截图模式不读写存档。

## 演示边界

这是加速体验的功能原型。普通访客间隔约 **22–36 秒**随机到来，首个稀有事件约在 **65 秒**触发，此后间隔约 **75–130 秒**；具体事件随天气池变化。8 秒收录风景也是为快速体验设定的节奏。在线和离线的事件安排、保底及概率均为演示参数，不代表正式游戏的稀有概率。

天气由玩家切换，**没有联网获取真实天气，也没有与现实昼夜和季节同步**。八种氛围由可分别替换的透明场景层、程序化天空、水面、云雾、雨雪和独立奇遇动画共同构成；当前素材仍为演示用美术。图鉴与布置偏好是结合真实生物灵感和幻想奇遇的游戏观察手记，不作为物种习性、投喂或天文知识库。离线事件使用演示时间槽补算，不重建真实天气历史。

尚未实现自由装修、连续筑巢故事、风景明信片、完整昼夜循环或倒计时工具。音乐与自然声开关会保存；滑杆调整本次混音，切换天气或声音预设会重新混音。计时只记录主动开启陪伴时的运行时长，不测量注意力。音频是原创合成占位素材，后续可替换为正式配乐。

## 工程文件

- `project.godot` / `main.tscn`：项目入口。
- `scripts/main.gd`：主界面、天气背景、观察收录、声音与陪伴流程。
- `scripts/window_scene.gd`：鸟、小动物、虫类、小船、塔灯、点击与观察记录；主场景的天气和新奇遇显示交给独立图层。
- `scripts/weather_stage.gd` / `scripts/weather_layers.gd`：场景图层、天气光色、云雾与雨雪运动。
- `scripts/encounter_layers.gd`：十种新奇遇的独立主体、运动、光效与退场。
- `scripts/field_guide.gd` / `scripts/guide_illustration.gd`：图鉴、分类筛选、详情、珍藏与图鉴插图。
- `scripts/diary_state.gd`：50 项图鉴定义、天气与偏好候选池、访客档案、纪念物、离线补算与存档兼容。
- `assets/art/layers_v1/`：运行时分层素材；`mountains.png`、`town_shore.png`、`tree.png`、`foreground.png` 为透明实景层，`water.png`、`cloud.png` 为水云素材，`deep_one.png`、`sunken_city.png`、`jellyfish.png`、`moon.png`、`island.png`、`stag.png` 为独立奇遇主体。
- `assets/art/v4/` / `assets/art/encounters_v1/`：此前的整张天气与奇遇原画，仅保留作参考，不再由运行场景加载。
- `assets/audio/`：原创合成 WAV 与音频检查清单。
